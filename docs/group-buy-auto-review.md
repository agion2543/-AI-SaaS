# 团购入口自动审核规则与异常处理（v1）

> 本规则只处理 SaaS 内的团购跳转链接，不代表抖音、美团或大众点评的官方审核、资质认证或授权；当前不接入任何真实平台 API，也不验证外部链接内容。

## 审核规则

| 规则 ID | 判定条件 | 自动结果 | 后续处理 |
|---|---|---|---|
| `GBR-SEC-001` | URL 格式无效、不是 HTTPS、含用户名/密码、显式端口（含 `:443`）、IP 地址、国际化/控制字符域名，或超过 1000 字符 | 拒绝提交 | 不创建或更新入口，不进入审核队列；提示修正后重试 |
| `GBR-CHAN-001` | 使用不支持的平台渠道 | 拒绝提交 | 选择抖音或美团/大众点评后重试 |
| `GBR-CHAN-002` | 所选平台与已识别的另一平台域名不一致 | 自动拒绝 | 保留被拒入口及规则编号/原因/审计记录；商家可改链重新判定 |
| `GBR-DOMAIN-001` | 域名形似平台官方域名，但不在该平台域名家族内（如官方域名后拼接其他域名） | 自动拒绝 | 保留拒绝记录；不可通过后台手工放行 |
| `GBR-DOMAIN-002` | 域名不在当前支持的平台域名家族内 | 自动拒绝 | 不允许跳转；平台管理员不能绕过 URL 安全校验放行 |
| `GBR-DOMAIN-003` | 域名属于所选平台域名家族，但不在精确自动通过白名单内 | 人工复核 | 进入待处理异常队列；管理员核对平台、门店和实际落地页后作出决定 |
| `GBR-LINK-001` | 抖音短链，或链接只指向平台根页、无法在本地确认具体团购落地页 | 人工复核 | 不访问短链、不追踪跳转；由管理员核实后处理 |
| `GBR-CHANGE-001` | 已通过入口的目标 URL 发生变化 | 人工复核 | 旧批准立即失效，入口暂停跳转；必须由管理员重新核验 |
| `GBR-STATE-001` | 商家/门店记录缺失、状态非启用或信息不一致 | 人工复核 | 入口保持不可跳转；核实并恢复状态后由管理员决定是否通过 |
| `GBR-AUTO-001` | HTTPS 安全检查通过；平台与精确域名匹配；非根页/非短链；商家和门店均为 active；不是已通过链接的改链 | 自动通过 | 记录系统审核人、规则编号、理由、时间及前后状态 |
| `GBR-ADMIN-001` | 管理员对待复核入口手动通过或拒绝 | 人工决定 | 必须填写核验/拒绝理由；通过前再次校验 URL 安全及商家/门店状态 |
| `GBR-ADMIN-002` | 管理员暂停或恢复入口 | 人工决定 | 记录管理员、原因、时间和前后状态；恢复仅适用于已通过且仍安全的入口 |

**当前精确自动通过域名：** 抖音 `life.douyin.com`；美团 `i.meituan.com`；大众点评 `www.dianping.com`。`v.douyin.com` 虽属于抖音域名家族，但视为短链，只进入人工复核。精确名单是应用内的保守配置，不代表平台官方域名清单的完整性；新增域名应先经人工核验和测试，再单独调整规则。

## 异常状态矩阵

| 入口状态 | 审核来源/规则 | 是否可跳转 | 管理员动作 |
|---|---|---:|---|
| `approved` | `auto` / `GBR-AUTO-001` | 仅在入口启用、商家和门店 active、未暂停时可跳转 | 可暂停；若商家修改目标链接，批准立即失效并转人工队列 |
| `pending` | `manual` / 对应异常规则 | 否 | 查看原因与记录，填写理由后通过或拒绝 |
| `rejected` | `auto` / 渠道或域名安全规则 | 否 | 可查看原因；不安全/域名不匹配的链接不能通过管理员按钮绕过 |
| `rejected` | `manual` / `GBR-ADMIN-001` | 否 | 商家修正链接后重新提交；保留拒绝历史 |
| `approved` + `admin_suspended=true` | 管理员暂停 | 否 | 仅在仍通过且状态满足要求时恢复 |
| `approved` + `enabled=false` | 商家停用 | 否 | 商家重新启用；无需重置审核状态 |
| `approved` + 商家或门店非 active | 经营状态拦截 | 否 | 修复商家/门店状态；后台审核通过并不覆盖经营状态门禁 |

所有入口状态转换均通过事务保存，并追加审计记录：规则编号（如适用）、结果/原因、系统或管理员身份、时间以及前后状态。审核历史没有修改/删除接口。安全预检失败的请求在入口记录创建前被阻断，因此不会产生一条可供后台查看的入口审计记录。

## 合成测试案例

以下均为本地虚构输入，仅调用规则引擎/临时 SQLite，不使用真实商家资料、生产数据、外部网络、支付或平台 API。

| 编号 | 合成输入/情形 | 预期结果 |
|---|---|---|
| T01 | active 商家/门店 + 抖音 `https://life.douyin.com/deal/demo` | 自动通过，`GBR-AUTO-001` |
| T02 | active + 美团 `https://i.meituan.com/deal/demo` | 自动通过，`GBR-AUTO-001` |
| T03 | active + 大众点评 `https://www.dianping.com/shop/demo` | 自动通过，`GBR-AUTO-001` |
| T04 | 抖音域名家族内未列入精确清单的 `https://shop.douyin.com/deal/demo` | 人工复核，`GBR-DOMAIN-003` |
| T05 | 抖音短链 `https://v.douyin.com/demo` | 人工复核，`GBR-LINK-001` |
| T06 | 抖音平台根页 `https://life.douyin.com/` | 人工复核，`GBR-LINK-001` |
| T07 | 选择抖音但提供美团 `https://i.meituan.com/deal/demo` | 自动拒绝，`GBR-CHAN-002`，不可跳转 |
| T08 | 仿冒样式 `https://life.douyin.com.attacker.example/deal` | 自动拒绝，`GBR-DOMAIN-001` |
| T09 | 任意外部域名 `https://coupons.example/deal` | 自动拒绝，`GBR-DOMAIN-002` |
| T10 | HTTP、URL 凭据、任意显式端口（含 443）、IP 或畸形 URL | 提交预检拒绝，`GBR-SEC-001`，不落库 |
| T11 | 商家或门店非 active | 人工复核，`GBR-STATE-001` |
| T12 | 已自动通过入口被改为另一条安全的精确白名单 URL | 旧批准失效、人工复核，`GBR-CHANGE-001` |
| T13 | 管理员无理由通过待复核项 | 操作被拒；有理由但 URL/商家状态不合格时仍不可放行 |
| T14 | 商家 A 尝试读取或修改商家 B 的门店入口 | 权限拒绝；不泄漏跨租户数据 |
| T15 | 自动判定、管理员通过/拒绝、暂停/恢复 | 每次状态转移均有规则/理由（适用时）、身份、时间和前后状态审计 |

## 本轮边界与下一步

这套规则只用于决定 SaaS 的站内跳转入口是否启用，不读取团购订单、核销、退款或支付状态；点击统计仍只是跳转点击数。下一步宜先用真实运营样本（人工脱敏后）校准域名白名单和异常原因，再明确人工审核 SLA、误判申诉与规则配置权限。只有在平台开放资质并完成接口授权、隐私/安全评估和幂等/对账设计后，才另行规划真实订单或核销 API；本轮不做这些接入。
